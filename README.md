## 📌 Sobre o Projeto

A **Agenda de Contatos** é um sistema de gerenciamento desenvolvido de forma **incremental**, onde cada versão evolui a estrutura anterior aplicando novos conceitos de Java e POO.

O objetivo é acompanhar na prática a progressão do aprendizado — partindo de variáveis simples até um CRUD completo com coleções dinâmicas.

---

## 🎯 Objetivo

Desenvolver uma Agenda de Contatos em Java, acompanhando a evolução das estruturas de armazenamento e das funcionalidades do sistema a cada etapa da disciplina.

## 📈 Evolução do Projeto

| Versão | Armazenamento | Principais Conceitos |
|--------|---------------|----------------------|
| **V.0.0.0** | Variáveis simples | `String`, `Scanner`, `if-else`, `switch`, `while` |
| **V.0.1.0** | Arrays | Vetores, índices, `for`, capacidade fixa |
| **V.0.2.0** | `List` + `ArrayList` | Coleções dinâmicas, `add()`, `get()`, `remove()`, `size()` |
| **V.0.3.0** ✅ (atual) | `List` + `ArrayList` | Alteração com `set()` e CRUD completo |

---

### 🔹 V.0.0.0 — Estrutura Base
Primeira versão do projeto. Utiliza variáveis simples para armazenar **apenas um contato por vez**, com menu interativo via `switch-case`.

### 🔹 V.0.1.0 — Arrays
Substituição das variáveis por **arrays**, permitindo armazenar múltiplos contatos com capacidade fixa de até 5 registros.

### 🔹 V.0.2.0 — Coleções Dinâmicas
Substituição dos arrays por **`List` e `ArrayList`**, eliminando o limite de registros e simplificando as operações de inserção e remoção.

### 🔹 V.0.3.0 — CRUD Completo *(versão atual)*
Adição da funcionalidade de **alterar contatos** com o método `set()`, completando as quatro operações básicas do sistema:

CREATE → Adicionar contato
READ → Listar e procurar contato
UPDATE → Alterar contato
DELETE → Excluir contato

## ▶️ Como Executar

**1. Clone o repositório:**
```bash
git clone https://github.com/WilsonStack/Agenda_contatos.git
```

**2. Acesse a versão desejada:**
```bash
cd Agenda_contatos/v0.3.0
```

**3. Compile:**
```bash
javac Main.java
```

**4. Execute:**
```bash
java Main
```
