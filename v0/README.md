# 📇 Agenda de Contatos - Versão V.0.0.0

> Primeira etapa do desenvolvimento incremental do projeto para a disciplina de **Programação Orientada a Objetos (POO)**.

---

## 📌 Visão Geral
Esta versão inicial estabelece a estrutura base da aplicação em console, utilizando entrada de dados via `Scanner`, laço de repetição `while` e estrutura de decisão `switch-case` para navegação pelo menu.

## 🛠️ Tecnologias e Conceitos Aplicados
* **Variáveis Primitivas e Strings:** Armazenamento isolado dos campos `nome`, `celular` e `email`.
* **Entrada de Dados:** Utilização do `java.util.Scanner`.
* **Menu Interativo:** Estrutura `switch-case` com laço de controle `while(continuar)`.

## ⚠️ Limitações da Versão
* **Capacidade:** Suporta o cadastro de apenas **1 contato por vez**.
* **Sobrescrita:** Qualquer novo cadastro substitui as variáveis do contato anterior.
