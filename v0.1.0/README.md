# Agenda de Contatos - V.0.1.0

Segunda versão do projeto de Agenda de Contatos.

## O que mudou nesta versão?
* Substituição de variáveis simples por **Arrays** (`String[]`)[cite: 1].
* Capacidade fixa para até 5 contatos (`capacidade = 5`)[cite: 1].
* Utilização do laço `for` para percorrer, buscar e listar contatos[cite: 1].
* Lógica para reorganizar e deslocar elementos do array após a exclusão[cite: 1].
* Controle de capacidade máxima para evitar estouro do array[cite: 1].
